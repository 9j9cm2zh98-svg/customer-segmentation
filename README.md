# Customer Segmentation — K-Means Clustering

A beginner-friendly machine learning project that uses **K-Means clustering** to segment
mall customers into five distinct groups based on their **Annual Income** and **Spending Score**.
Includes a **Streamlit dashboard** to explore the clusters interactively.

---

## What You Will Learn

- How K-Means clustering works
- How to use `StandardScaler` to prepare data for distance-based algorithms
- How to use the **Elbow Method** to choose the right number of clusters
- How to build a simple interactive dashboard with **Streamlit**

## Setup

### 1. Clone or download the project

```bash
git clone <your-repo-url>
cd customer-segmentation
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
source venv/bin/activate        # macOS / Linux
venv\Scripts\activate           # Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

---

## How to Run

### Step 1 — Run the training script

This runs the full ML pipeline and saves all outputs to disk.

```bash
python train.py
```

You will see step-by-step console output:
- Dataset shape and sample rows
- Null value check
- Inertia values for K=1 to K=10 (look for the elbow at K=5)
- Cluster sizes after training
- Confirmation of all saved files

### Step 2 — Launch the dashboard

```bash
streamlit run app.py
```

Your browser will open automatically at `http://localhost:8501`.

## What Each File Does

| File | Description |
|---|---|
| `data/customers.csv` | The raw Kaggle Mall Customer Dataset. 200 customers with CustomerID, Genre, Age, Annual Income, and Spending Score. |
| `train.py` | The complete ML pipeline. Loads data, scales features, runs the Elbow Method, trains K-Means with K=5, and saves all outputs. |
| `app.py` | The Streamlit dashboard. Reads the clustered data and displays KPI cards, a scatter plot, a bar chart, and a filterable data table. |
| `requirements.txt` | Lists all Python packages needed. Install with `pip install -r requirements.txt`. |
| `README.md` | This setup and usage guide. |

## The 5 Customer Segments

After running `train.py`, K-Means discovers these five segments:

| Cluster | Annual Income | Spending Score | Who Are They? |
|---|---|---|---|
| 0 | High | Low | Careful High-Earners — earn a lot but spend conservatively |
| 1 | Low | High | Impulsive Spenders — low income but high spending |
| 2 | Medium | Medium | Average Customers — the typical mall visitor |
| 3 | High | High | Target Champions — high income and high spending |
| 4 | Low | Low | Budget-Conscious — low income and low spending |

> The exact cluster numbers may vary between runs. What matters is the shape of the
> scatter plot — the five groups are always clearly visible.

## Dashboard Features

- **Sidebar filter** — select one or more clusters to focus on
- **KPI cards** — total customers, average annual income, average spending score
- **Scatter plot** — Annual Income vs Spending Score, coloured by cluster
- **Bar chart** — customer count per cluster
- **Data table** — raw customer records for selected clusters
